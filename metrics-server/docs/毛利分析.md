毛利率分析V1.0 - 0303
需求来源： 
潜客Kaimay,Q1 "Advice how do we improve gross margin?"
使用场景：
综合分析企业毛利率水平，按销售、采购、仓储三个维度分析，发现问题并针对性给出优化建
议。
前提假设：
1. 默认金额都转化为「%本位币」
2. 默认净值，剔除税金额
过滤条件:
1. 时间范围：上一整年或过去一年，按入账时间「%var」
2. 实体范围：单公司
3. 物料范围：按产品组分析，暂不考虑其他维度
4. 客户范围：全部，如果需要，可以按客户分析
关键数据&算法:
1. 毛利率计算公式：
1. 毛利率 = (营业收入 - 营业成本) / 营业收入 ×100%; 以下是按照各因子拆解需要
分析的明细说明和定义
2. 数据视图：MTC_VW_AI_JournalEntry。总账层面 - Accout Code级别的日记账
分录明细数据，科目上没有固定表示科目类型，所以需要添加知识识别出哪些是
收入科目，哪些是成本科目。

2.2. 主营收入的分析知识
2.2.1. 按「%产品组」维度的销量占比的分析方法
## 以2.1.1.1产品维度为例，设计分析计算逻辑和推荐分析。维度的分析按
变量替换原则，重新计算数据，计算逻辑和框架基本不变。
计算逻辑：按「%产品组」分析在「%某时间范围」内的销售总额（全部销
售金额），以及在「%销售总金额」中的占比；「%产品组」销售额占比 =
「%产品组」销售额 / 销售总金额 *100%；
排序逻辑：按「%销售占比」降序排列；计算获取销售占比百分位，「%销
售占比前20%分位」、「%销售占比前80%分位」；
推荐分析：
按 「%销售占比」在20%以内的分为重点关注类，即销售金额贡献大；
推荐结论，集中投入主要资源，扩大重点关注类「%产品组」销售规
模，有助于显著提升毛利率；
按 「%销售占比」 在20%与80%之间的分为常规类，即销售金额贡献
适中；推荐结论，保持常规类「%产品组」的销售规模，稳住收入，保
障投入资源，适当提升销售额，有助于提升毛利率；
按 「%销售占比」 在80%以外的分为不重要类，即销售金额贡献小；
推荐结论，低销售额贡献产品，对销售金额影响较小，少量投入资源维
护即可。
2.2.2. 产品销售额结合增减趋势的分析方法
计算逻辑：按「%产品组」统计分析在「%某时间范围」内的销售金额的
环比增减趋势；
排序逻辑：按环比增长率降序排列；计算获取环比增长率「%阀值」（默
认30%）；
推荐分析：
环比增长率在「%阀值」以上，说明增长率较高；
且销售额占比在20%分位以内的；推荐结论：特别关注，集中投入资
源，扩大规模，大幅提升毛利率；
且销售额占比在20%分位与80%之间的；推荐结论：重点关注，常规
投入资源，稳定规模，平稳提升毛利率；
且销售额占比在80%分位以外的；推荐结论：适时关注，必要时投入
资源，提升销售规模，少量提升毛利率；
例外说明，环比增长率突然增加或持续增加（默认连续3个月），属
于偏差较大的情况，说明有异动，需要特别分析异动原因，也许“黑马”正
在孕育中。
环比增长率在「%阀值」以下，说明增长率较低；
且销售额占比在20%分位以内的；推荐结论：特别关注，销售额出现
大幅下跌，需要分析原因，减轻对毛利率的负向影响；
且销售额占比在20%分位与80%之间的；推荐结论：重点关注，销售
额出现较大下跌，需要分析原因，减轻对毛利率的负向影响；
且销售额占比在80%分位以外的；推荐结论：适时关注，必要时投入
资源，对毛利率影响不大；
例外说明，环比增长率突然降低或持续降低（默认连续3个月），属
于偏差较大的情况，说明有异动，需要特别分析异动原因，防止大幅下滑
影响毛利率。
2.2.3. 产品销售额结合客户销量增减趋势的分析方法
计算逻辑：按「%产品组」统计分析在「%某时间范围」内的对「%某客
户」的销售额增减趋势/环比；
排序逻辑：按「%某客户」销售额增长环比联合「%产品组」降序排列；
计算获取前5% 分位，前5%-20% 分位，前20%以外分位
推荐分析：
按 「%客户」销售额增长在5%以内的分为战略类，联合看「%产品
组」销售金额；推荐结论，战略类客户贡献巨大，集中投入优势资源，
扩大战略类「%客户」销售规模，有助于显著提升毛利率；
按 「%客户」销售额增长在5%与20%之间的分为重要，联合看「%产
品组」销售金额；推荐结论，重要类客户贡献较大，保持销售规模，稳
住收入，保障投入资源，适当提升销售额，有助于提升毛利率；
按 「%客户」在20%以外的分为常规类，联合看「%产品组」销售金
额；推荐结论，常规类销售金额贡献小，对销售金额影响较小，少量投
入资源维护即可。

别关注，缓慢类产品的库存活动，定期复盘，防止库存积压，降低库存
