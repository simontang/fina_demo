## 4. Price/Volume 分解（Revenue Bridge，OINV−ORIN）

用 **OINV（发票）− ORIN（贷项凭证/退货）** 做净销售额与净数量，拆解 H2 相对 H1 的变化来源。

| 产品组 | H1 净销售额 | H2 净销售额 | 变化 | H1 净数量 | H2 净数量 | ASP（H1） | ASP（H2） | 量效应 | 价效应 |
|--------|------------:|------------:|-----:|----------:|----------:|----------:|----------:|-------:|-------:|
| Confectionary | 8,290,718 | 10,952,247 | +2,661,528 | 184,978 | 245,958 | 44.82 | 44.53 | +2,733,118 | -71,589 |

结论：
- 2025 H2 的糖果增长几乎完全来自 **销量增长**（量效应 +2.73M），ASP 基本持平略降。
- 因此“扩规模”本身并不能保证毛利改善，毛利提升要回到：渠道结构、折扣条款、采购成本、补贴返利与信用成本。

## 5. 资金效率：周转与 GMROI（方向性）

基于 `OIVL.SumStock` 推导期初/期末库存并取均值（注：OIVL 与 STOCK 快照口径存在差异，绝对值需对账后再对外引用）。

| 指标 | 值 |
|------|---:|
| Confectionary 销售成本（SalesCost） | 16,677,013 |
| 期初库存价值（OIVL，2025-01-01） | 2,301,064 |
| 期末库存价值（OIVL，2026-01-01） | 2,664,577 |
| 平均库存 | 2,482,821 |
| **周转次数（SalesCost/AvgInv）** | **6.72x** |
| **GMROI（交易口径毛利/AvgInv）** | **1.57x** |

经营含义：
- 周转不差（6.72x），但 GMROI 仍偏低，说明糖果是“**规模大、占资重、利润率不高**”的品类；提升毛利率的杠杆大于单纯追求规模。

## 6. 优先级待办（建议落地顺序）

- **P0：口径对齐**：对齐 JE 与 SalesRevenueCost 的差异（尤其补贴/返利/条款的归属），形成“可下钻但不失真”的经营毛利口径。
- **P0：CC2 归类治理**：把未归类渠道的 10%+ 收入归并到明确的本地/出口/其他渠道，以免情景决策误判。
- **P1：SKU 负毛利止血**：KitKat 两个负毛利 SKU 先核查口径再止损；Rocher T30 做“条款+定价+采购”联动提升。
- **P1：出口信用收敛**：把“扩出口”与“信用政策/回款机制”绑定，否则真实利润率会被坏账吞噬。
- **P2：月度经营看板**：Revenue Bridge + 渠道/客户利润矩阵 + SKU 预警 + 周转/GMROI 自动刷新。
