糖果业务账面毛利率健康（**19.4%**，JE 口径），但利润质量被**出口信用风险（AR 老化与集中度）**与**资本占用（AR + 库存）**显著侵蚀；董事会真正要决策的是“信用与资本回报约束下的增长方式”，而不是“渠道取舍式的简单口号”。

### 2.5 模型一是否需要“按产品维度拆分”？

结论：在本报告（董事会级、JE 毛利唯一口径）里，**不建议把“产品维度拆分”作为模型一的必选项**，原因是：  
- JE 视图用于会计记账与成本归集，天然优势是“口径统一 + 可对账”，但**不天然携带稳定的 SKU/品牌/品类（ItemCode/ItemGroup）明细字段**；强行做产品拆分，容易把口径带偏，导致董事会讨论从“资本与风险结构”退化为“SKU 层口径争论”。  
- 董事会需要的是“结构性矛盾的识别与治理优先级”（信用、资本、条款、主数据），而不是 SKU 级毛利推算。  

如果需要做“产品/品牌”层面的经营下钻（例如“产品毛利交叉分析”），建议放到经营分析文件中，且明确标注口径为 `MTC_VW_AI_SalesRevenueCost`（并与 JE 进行差异对账），避免与董事会口径混用。

## 3. 模型二：利润桥（Profit Bridge）——从账面毛利到真实经营利润

### 3.1 口径说明（哪些来自 JE，哪些是经营假设）

本模型回答一个董事会问题：  
“糖果业务看起来 19.4% 的账面毛利，为什么 CFO 视角只有 ~10% 的真实经营利润？”  

拆解原则：  
- [A] 账面毛利：只用 JE 的糖果科目（401020100/501030100）。  
- [B] 商业毛利：在 [A] 基础上，叠加 JE 中与业务条款/费用相关的 5xx/502xx 科目（同为会计口径，但不属于 501030100）。  
- [C] 真实经营利润：在 [B] 基础上，再计入“坏账拨备与资金成本”等经营假设（用于董事会做风险与资本回报判断）。

### 3.3 管理层要点（从数字回到动作）

- 为什么 [B] > [A]：补贴/佣金等在 JE 中体现为 502xx 的“抵减项”，会抬高商业毛利；但该部分具有续约与集中度风险，不能当作“稳定盈利能力”。  
- 真实经营利润的最大不确定性来自坏账：在当前假设下，坏账拨备（-11.3%）是把 22.5% 拉回 10.6% 的主因。

### 4.6 CCC/DSO/DIO（把“体感”变成可复核的计算表）

为避免 CCC 讨论陷入口径争论，本报告提供“可复核的组成项”，并将“供应商账期（DPO）”单列为待对齐项。  

| 指标 | 计算公式 | 结果 | 备注 |
|---|---|---:|---|
| DSO（天） | AR（Food Export+Local） ÷ 2025 糖果收入 × 365 | ~255 | AR 取 `MTC_VW_AI_CUSTBAL` 的开放项余额；分母用糖果收入（JE） |

## 5. 模型五：CFO / CEO 的关键问题（用数据把问题说清楚）

> 本部分不是“泛泛的管理问题”，而是把董事会应追问的 10 个问题，绑定到本报告已经暴露的具体数据异常与治理缺口。  

### 5.1 CFO 的 5 个核心问题（财务与风险）

**Q1：糖果业务的“经济利润”是否成立？**  
- 数据依据：模型二 Profit Bridge  
- 结论（基于当前假设）：账面毛利率 19.4%（[A]）并不等价于经济利润；若按逾期 180d+ × 50% 计提，真实经营利润率约 10.6%（[C]）。  
- 董事会追问：坏账计提机制是否应制度化前置（而不是事后一次性冲击）？  

**Q2：出口 AR 风险的“规模、老化、集中度”到底有多大？**  
- 数据依据：模型三 4.1~4.4  
- 结论：Export AR 10.19M（占 Food AR 的 75.9%）；其中 731+ 为 2.87M（28.1%）。  
- 董事会追问：是否设定“>180 天 AR 占比上限”“单一客户敞口上限”“单一负责人敞口上限”？  

**Q3：补贴/佣金对盈利的依赖度是否可控？**  
- 数据依据：模型二（补贴/佣金 1.829M）  
- 结论：补贴/佣金约 1.83M，相当于账面毛利（3.74M）的约 49%（规模级别）；如果续约/条款变化，会对利润稳定性造成巨大波动。  
- 董事会追问：是否要求把“补贴条款”从年度谈判前置到客户合同与价格体系，并做多品牌/多客户分散？  

**Q4：渠道/部门维度（CC2/CC1）是否足以支撑资源配置？**  
- 数据依据：模型一（未归类收入 15.2%；CC2 Name 缺失 696 行）  
- 结论：在未归类渠道完成归并前，任何“按渠道”资源配置会存在 15% 量级的结构噪声。  
- 董事会追问：是否设立“渠道主数据治理”责任人，形成月度闭环（目标：未归类收入 < 2%）？  

**Q5：库存估值差异会对资本回报判断造成多大偏差？**  
- 数据依据：模型三 4.5  
- 结论：库存估值口径差异 1.15M（2.48M vs 1.34M）会把 GMROI 从 1.50x 拉到 2.79x；如果把资金成本纳入，资本占用的利润侵蚀可能被低估。  
- 董事会追问：是否将“库存估值口径对账”作为 P0（在 2 周内给出可审计解释）？  

### 5.2 CEO 的 5 个核心问题（经营与组织）

**Q1：如何把 Export 从“会计盈利”变成“经济盈利”？**  
- 数据依据：Export AR 的 731+ 占比 28.1%，且高度集中在少数客户/负责人。  
- 经营含义：在不重构信用政策前，Export 的规模增长会放大资金占用与坏账尾部风险，导致“收入增长但经济利润不增长”。  

**Q2：Local 的角色是什么，怎么放大“利润质量优势”？**  
- 数据依据：Local 毛利率 26.1%，显著高于 Export（17.8%）；且 Local-MT 毛利率 34.5%（渠道 Top 12）。  
- 经营含义：Local 可作为利润与现金流稳定器，但需要通过 MOQ/交付节奏/运营效率优化，释放规模弹性。  

**Q3：条款与费用（Trading Term/配送/折扣）到底是“结构问题”还是“可治理问题”？**  
- 数据依据：Trading Term -2.6%，Carriage -2.2%，Discount -1.0%，Expired -0.6%。  
- 经营含义：这些项在规模增长下会线性放大，必须进入“定价与合同条款”的前置治理，而不是事后财务解释。  

**Q4：未归类渠道（15.2%）代表什么组织问题？**  
- 数据依据：模型一 2.3  
- 经营含义：这是“数据主线断裂”问题：业务口径、渠道归属与财务核算之间未形成强制约束；会直接拖慢决策速度。  

**Q5：未来 12 个月最大的经营不确定性是什么？**  
- 数据依据：731+ AR 高占比 + 补贴依赖度高 + 库存估值口径未统一  
- 经营含义：最大不确定性不在毛利率，而在“现金能否收回来 + 补贴能否续上 + 库存是否真实可变现”。

### B. 糖果按 CC2 分组（JE，2025）

```sql
SELECT
  CASE
    WHEN "OcrCode2" LIKE 'Local-%' THEN 'Local'
    WHEN "OcrCode2" LIKE 'Exp-%' THEN 'Export'
    ELSE 'Unclassified'
  END AS channel_group,
  ROUND(SUM(CASE WHEN "Account" = '401020100' THEN "Credit" - "Debit" ELSE 0 END), 0) AS revenue,
  ROUND(SUM(CASE WHEN "Account" = '501030100' THEN "Credit" - "Debit" ELSE 0 END), 0) AS cogs

WHERE "RefDate" >= '2025-01-01' AND "RefDate" < '2026-01-01'
  AND "Account" IN ('401020100','501030100')
GROUP BY
  CASE
    WHEN "OcrCode2" LIKE 'Local-%' THEN 'Local'
    WHEN "OcrCode2" LIKE 'Exp-%' THEN 'Export'
    ELSE 'Unclassified'
  END
ORDER BY revenue DESC;
```

### C. Food AR 暴露与老化（开放项余额，现状）
