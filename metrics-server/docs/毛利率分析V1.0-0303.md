### 3.4 SKU 级毛利率估算（来源：ODLN × STOCK）

> **为何需要此维度**：JournalEntry 5xx 科目只能做到产品组级别的 COGS，无法下钻到单个物料（SKU）。通过 `ODLN.Quantity × STOCK.AvgPrice` 估算每个 SKU 的出库成本，结合 `ODLN.LineTotal`（售价）得出 SKU 级毛利率，用于识别品类内部的高/低毛利 SKU。

#### 3.4.1 计算逻辑（SQL，已执行）

```sql
WITH stock_cost AS (
    SELECT
        "ItemCode",
        SUM("OnHand" * "AvgPrice") / NULLIF(SUM("OnHand"), 0) AS "WeightedAvgPrice"
    FROM "MTC_VW_AI_STOCK"
    GROUP BY "ItemCode"
    HAVING SUM("OnHand" * "AvgPrice") > 500   -- 过滤零库存/近零库存物料
)
SELECT
    o."ItmsGrpNam"                                                       AS "ProductGroup",
    o."ItemCode",
    o."Dscription",
    ROUND(s."WeightedAvgPrice", 2)                                       AS "AvgCostPrice",
    SUM(o."Quantity")                                                    AS "TotalQtySold",
    ROUND(SUM(o."LineTotal"), 0)                                         AS "TotalRevenue",
    ROUND(SUM(o."Quantity" * s."WeightedAvgPrice"), 0)                   AS "EstimatedCOGS",
    ROUND((SUM(o."LineTotal") - SUM(o."Quantity" * s."WeightedAvgPrice"))
        / NULLIF(SUM(o."LineTotal"), 0) * 100, 1)                       AS "EstimatedGM_Pct"
FROM "MTC_VW_AI_ODLN" o
JOIN stock_cost s ON o."ItemCode" = s."ItemCode"
WHERE YEAR(o."DocDate") = 2025 AND o."LineTotal" > 0
GROUP BY o."ItmsGrpNam", o."ItemCode", o."Dscription",
         s."WeightedAvgPrice", s."TotalOnHand", s."TotalStockValue"
ORDER BY o."ItmsGrpNam", "TotalRevenue" DESC;
```

查询执行后发现，糖果/饮品/啤酒等品类的绝大多数 SKU 显示毛利率 85–100%，明显异常。根因是**销售 UOM（箱/carton）与库存 UOM（个/piece）不一致**：

## 五、数据说明

### 5.1 核心假设与局限

| 项目 | 说明 |
|------|------|
| 毛利计算口径 | JournalEntry 5xx科目为成本（移动平均法），4xx科目为收入；**品类级 COGS 精确口径** |
| 产品组识别 | JE无产品组字段，依据科目代码前缀映射（见5.2节） |
| 库存周转率 | 分子使用 ODLN.LineTotal（**销售价**，非成本），绝对倍数偏高；比较品类间相对快慢有效，但不宜直接引用绝对值。精确做法：分子改用 JE 5xx COGS 或 `ODLN.Quantity × STOCK.AvgPrice` |
