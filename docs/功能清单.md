# Fina 智能体平台 · 功能清单

> 面向潜在客户与 IT 团队。Fina 智能体平台 = **Agent 管理与治理底座**（框架底层能力）+ **业务应用能力**（Fina Demo）。
> 本文只描述"能做什么"，不展开底层技术细节。

**图例**：✅ 内置功能，开箱即用 ｜ 🔌 可扩展 / 插件能力，需额外配置 ｜ ⚙️ 可自定义配置

---

# 第一部分 · 平台底座能力（Agent 管理与治理）

## 一、Agent 生命周期管理

### 1.1 创建与配置
| 功能 | 说明 |
|------|------|
| ✅ Agent 创建向导 | 可视化引导创建 Agent，支持选择类型、配置参数 |
| ✅ 模板市场 | 预置常用 Agent 模板，快速启动 |
| ✅ 多类型 Agent 支持 | 支持多种 Agent 架构（详见下节） |
| ✅ 自定义提示词 | 灵活配置 Agent 行为和角色定位 |

| ✅ Agent 继承机制 | 支持子 Agent 继承父 Agent 配置 |

### 1.2 多类型 Agent 架构
| 类型 | 说明 |
|------|------|
| **REACT** | 单 Agent 工具调用循环，最常用的交互模式 |

| **PROCESSING** | 拓扑强制执行的工作流编排 |
| **WORKFLOW** | DSL 声明式工作流，步骤级编排 |
| **A2A_REMOTE** | 桥接外部 A2A 协议 Agent |

### 1.3 部署与版本
| 功能 | 说明 |
|------|------|
| ✅ 一键部署 | 简化部署流程，快速上线 Agent |
| ✅ 版本管理 | 支持 Agent 配置版本化，可回滚 |
| ✅ 环境配置 | 区分开发、测试、生产环境 |

### 1.4 运行时管理
| 功能 | 说明 |
|------|------|
| ✅ 状态监控 | 实时查看 Agent 运行状态 |
| ✅ 启停管理 | 支持 Agent 的启动、暂停、终止 |

## 三、工作流编排（Workflow DSL）

### 3.1 步骤类型
| 类型 | 说明 |
|------|------|
| **AgentStep** | 调用工作流的 Agent 处理任务 |
| **ConditionStep** | 条件分支，支持 if/else 和多分支 switch |
| **HumanStep** | 暂停等待人工输入 / 审批 |
| **MapStep** | 遍历数组，并发处理后聚合结果 |
| **ParallelStep** | 并行执行多个步骤 |
| **EndStep** | 结束状态，标记成功或失败 |

### 3.2 工作流能力
| 功能 | 说明 |
|------|------|
| ✅ 声明式编排 | JSON 格式声明工作流，简洁直观 |
| ✅ 条件路由 | 根据执行结果动态路由 |
| ✅ 并行执行 | 多个步骤同时执行，提升效率 |
| ✅ 批量处理 | Map-Reduce 模式处理大批量数据 |
| ✅ 人工介入 | 关键节点支持人工审批 |
| ✅ 结果引用 | 步骤间通过 `{{stepId}}` 引用结果 |
| ✅ 模板变量 | 支持 `{{input}}` 用户输入和 `{{item}}` 遍历元素 |

### 3.3 预置工作流模板
线性流水线 A → B → C ｜ 条件路由 ｜ 并行汇总 ｜ 审批流程

# 第二部分 · 业务应用能力（Fina Demo）

## 十四、语义指标中台（Semantic Metrics）

将物理数据源转化为可复用的语义表与业务指标（指标中台建模），并支持语义查询。

| 功能 | 说明 |
|------|------|
| ✅ 数据源探索 | 列出授权数据源、读取表授权范围、只读 SQL 探查表结构与取值分布（PostgreSQL / SQL Server / HANA） |
| ✅ 语义表发布 | 发布列角色（维度/度量/时间）、业务标签、粒度、血缘来源 |
| ✅ 指标发布 | 聚合型（sum/avg/count）与派生型（比率/公式）指标，含维度、时间上下文、AI 检索上下文（同义词、极性、解释） |
| ✅ 语义指标查询 | 按指标名取定义并执行语义查询，直接得到业务数字 |
| ✅ 目标协商与质量门禁 | 先与用户确认目标、消费者、验收证据，经 FEP 循环发布并验证（HITL） |
| ✅ 验证与持续修正 | 按验收标准跑查询验证，失败时更新信念并重新发布 |
| ✅ 指标-数据源服务 | 多数据源管理、连接池监控、指标索引/明细、即席 SQL（带权限校验）、多租户与数据源级 API Key 权限 |

## 十五、SAP B1 连接器

通过 OData Service Layer 连接 SAP Business One，覆盖 **BP / 物料 / 订单 / 库存 / 财务** 五大领域。

| 功能 | 说明 |
|------|------|
| ✅ 接口元数据搜索 | 按名称或中文语义搜索 EntitySet / FunctionImport，返回主键、字段、可用 `$select`/`expand` |
| ✅ 数据查询与增删改 | 订单、发票、交货单、报价、退货、采购单、库存收发货、转储、盘点等的 OData 操作 |
| ✅ 主数据访问 | 客户/供应商、物料、价格清单、销售员、仓库/库位、批次/序列号 |
| ✅ 财务能力 | 银行对账单及明细、内部银行账户、会计科目表、到岸成本、汇率查询与设置 |
| ✅ 全量代理与多租户 | B1 会话自动登录/续期/重试；按 `X-Tenant-Id` + `X-Company-DB` 支持多公司库 |
| ✅ 业务对象逻辑视图 | 订单/交货/发票/应收应付/客户/供应商等逻辑视图，统一多表关联口径 |
| ✅ 邮件订单自动化 | 邮箱收件、查询、意图识别（采购/下单）、采购订单摘要抽取、派发给 Agent 执行、工作流状态追踪 |
